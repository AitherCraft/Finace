            Extra security

            Type of extra security

            The PIN is asked when you open the app and every time you leave it. It is stored scrambled, never as the numbers you typed. It locks the screen on this app. It does not replace your account password.

            The code is a 6 digit number sent from Referee Finance. It lasts 10 minutes. Check spam if it does not show up.
